# JSSDM 2022 Section 17: army symbols quick reference

Source: Joint Services Staff Duties Manual 2022, Section 17 (Army Symbols) and its annexes. The original pages are in `../symbols/pages/` named by page number (e.g. `17F-8.png`). Ready-made SVGs of the symbols below are in `../symbols/svg/key-*.svg`, and `../scripts/jssdm_symbols.py` draws them in code.

## Colours (para 1704)

| Colour | Use |
|---|---|
| Blue | Friendly units, posts, installations, equipment, activities |
| Red | Enemy units, posts, installations, equipment, activities |
| Green | Friendly and enemy man-made obstacles (minefields, ditches, road blocks); friendly para-military forces (BGB, Coast Guard) |
| Yellow | Friendly and enemy NBC events and contaminated areas |
| Black | Grid intersections, superscription and all other markings |

All writing that goes with a symbol is in its colour and in **block capitals** (1704e). One-colour drawings: forces drawn with **double lines**; equipment marked `EN` (1713). Any other colour or non-standard sign must be explained in a legend (1703, 1704e).

## Basic rules

| Rule | Para | Page |
|---|---|---|

| Role indicator goes inside the basic sign (Annex A) | 1707 | 17A-1 to 17A-3 |

| Unit designation on the right, sub-unit on the left | 1708 | 17-3 |
| Area in a state of defence: "goose egg", size indicator on the line, no unit symbol; unit not in defence: symbol inside the goose egg | 1709 | 17-3 |
| Movement on a route: single arrow | 1710 | 17-4 |
| Solid line = actual location / objective / boundary; broken line = future or projected | 1714 | 17-4 |
| Date-time group under the symbol | 1715 | 17-4 |
| `?` where information is doubtful | 1716 | 17-5 |
| Destroyed equipment / installation marked X | 1717 | 17-5 |
| Reinforced (+), detached (-), combat grouping e.g. 7H (3,1) | 1721, 1722 | 17-6 |
| Information fields A–R around a symbol | 1724, 1725 | 17-7 to 17-10 |

## Annex E: electronic activities

Inverted triangle with: arrow up = direction finding, arrow sideways = emitting, arrow down = intercepting, zigzag = jamming (page 17E-2).
